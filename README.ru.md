## Что хранится в репозитории?

**Filamentra DataSource** — каталог данных для [Filamentra](https://github.com/4FusionLab/Filamentra), будущего аддона Autodesk Fusion от **4FusionLab**.

Аддон позволит выбирать реальные филаменты и устанавливать соответствующий **визуальный Appearance** в текущий проект Fusion по запросу. В этом репозитории находятся **данные каталога**, а не интерфейс и не код аддона.

- **Производители:** названия брендов и подтверждающие ссылки.
- **Линейки:** тип полимера, фактура и заявленные особенности.
- **Цвета:** официальные названия, постоянные ID, цветовые референсы и происхождение значений.
- **Доставка:** версионированные, прошедшие проверку архивы каталога через GitHub Releases.
- **Независимость:** справочник не должен зависеть от Autodesk Fusion.

## Структура каталога

```text
catalog/
├── brands/
│   └── <manufacturer>/
│       ├── brand.json
│       ├── <product-line>.json
│       └── ...
└── schema/
    └── line.schema.json

docs/
├── CATALOG_FORMAT.md
└── DISTRIBUTION.md
```

Один JSON на линейку со всеми её цветами. Логическая иерархия — **производитель → материал (PLA/PETG) → линейка → цвет**. Полимер указан в данных и используется для группировки, без дополнительного уровня физических папок.

Подробнее — в [описании формата](docs/CATALOG_FORMAT.md) и [спецификации визуальных материалов для Fusion API](docs/MATERIAL_APPEARANCE_SPEC.md).

### Первые данные каталога

- **Bambu Lab:** [24 линейки и 246 вариантов PLA/PETG](catalog/brands/bambu-lab/) из зафиксированной версии [официального реестра BambuStudio](catalog/sources/bambu-lab.json), с кодами и многоцветными образцами.
- **Приоритет — достоверность:** **605** позиций с образцами производителя или документированным измерением физического отпечатка для основного предпросмотра; **325** оценочных HEX и **126** записей без цвета скрываются по умолчанию. Полный исходный каталог: **13 брендов с материалами / 83 линейки PLA/PETG / 1019 вариантов**. [Политика качества](docs/VISUAL_DATA_QUALITY.md) · [119 незаполненных вариантов](docs/UNRESOLVED_COLORS.md) · [Статус](docs/CATALOG_PROGRESS.md).
- **Новые бренды:** [Anycubic](catalog/brands/anycubic/) — 68 цветов, [Polymaker](catalog/brands/polymaker/) — 15, [REC](catalog/brands/rec/) — 24. [FDplast](catalog/brands/fdplast/) — 4 PETG, [BestFilament](catalog/brands/bestfilament/) — 6 PLA/PETG с **оценочными** HEX и точными SKU. [НИТ](catalog/brands/nit/) пока остаётся без подтверждённых числовых цветов. [Аудит российских источников](docs/RUSSIAN_COLOR_SOURCE_AUDIT.md).
- **Визуальные пресеты:** [18 типовых профилей](catalog/presets/) с процедурными Normal/Roughness-картами. Все фактуры некалиброванные. [Генератор и методика](docs/TEXTURE_GENERATION.md) · [Предпросмотр фактур](https://4fusionlab.github.io/Filamentra-DataSource/textures.html).
- **План наполнения:** [статус каталога](docs/CATALOG_PROGRESS.md) и порядок добавления оставшихся линеек и российских производителей.
- **Контроль структуры:** [JSON Schema](catalog/schema/) и [проверка каталога](.github/workflows/validate.yml).

**Принцип достоверности:** используем официальные цвета, а недостающие оптические свойства заменяем явно обозначенными пресетами, которые впоследствии нужно откалибровать по физическим образцам и рендерам Fusion.

## Посмотреть каталог в браузере

**[Демо Filamentra](https://4fusionlab.github.io/Filamentra-DataSource/)** — интерактивный каталог PLA/PETG с фильтрами по брендам, линейкам и цветам, визуальными образцами и источниками данных. Многоцветные градиенты показываются условно — это не физически точный рендер Fusion.

Демо публикуется через [GitHub Actions](.github/workflows/publish-demo.yml) **только вручную через Run workflow**. Изменения в `main` проходят автоматическую валидацию, но не запускают новую публикацию. [Правила публикации и локальная сборка](docs/DEMO_PAGES.md).

## Качество важнее количества

- **Только реальные продукты.** Не выдумываем линейки, цвета и артикулы.
- **Проверяемость.** Предпочитаем информацию производителя, фиксируем источник и дату проверки.
- **Оценки отдельно от фактов.** HEX с сайта и фото катушки не гарантируют точного совпадения с отпечатком.
- **Постоянные ID.** Переименование оттенка не должно ломать ссылки на него.
- **Визуальный материал — не инженерный.** Каталог не заменяет достоверные физические свойства для расчётов.
- **Права на контент.** Не копируем фотографии и текстуры производителей без разрешения.

## Релизы и совместимость

Версия наполнения каталога отделена от версии схемы JSON:

| Элемент | Назначение |
| --- | --- |
| Релиз каталога (`vX.Y.Z`) | Новые и исправленные данные |
| Версия схемы (`1`, `2`, …) | Формат, понятный аддону |
| `catalog-index.json` | Версии, совместимость, архивы и контрольные суммы |
| `catalog-schema-vN.zip` | Снимок каталога в конкретном формате |

Аддон должен выбирать **последнюю совместимую** версию и хранить локальный кэш для работы без сети. Обновление каталога не должно самопроизвольно менять уже установленные Appearance в существующих моделях.

**Статус: реестр BambuStudio импортирован, остальные бренды заполнены частично.** Визуальные пресеты пока не откалиброваны в Fusion, а проверенного релиза каталога ещё нет. Подробности — в [статусе наполнения](docs/CATALOG_PROGRESS.md) и [доставке](docs/DISTRIBUTION.md).
