# Каталог производителей Filamentra

[English](README.md)

Для каждого производителя создаётся каталог с одним `brand.json` и отдельным JSON-файлом для каждой реальной линейки продуктов.

```text
brands/
└── bambu-lab/
    ├── brand.json
    └── pla-matte.json
```

Для **Bambu Lab** импортированы 24 семейства PLA/PETG и 246 вариантов из закреплённой [ревизии реестра BambuStudio](../sources/bambu-lab.json). Для других китайских брендов выполнен частичный проверенный импорт; см. [статус наполнения](../../docs/CATALOG_PROGRESS.md).

Каждая линейка ссылается на базовый визуальный пресет в `../presets/`. Линейка и отдельные цвета могут переопределять параметры пресета **при наличии подтверждений**; цветовые данные производителя чётко отделяются от визуальных оценок Filamentra. Не создавайте отдельный файл для каждого цвета и не выдавайте оценочную шероховатость за официальную спецификацию производителя.

См. [формат каталога](../../docs/CATALOG_FORMAT.ru.md), [сопоставление с Fusion Appearance](../../docs/MATERIAL_APPEARANCE_SPEC.ru.md) и [руководство для участников](../../CONTRIBUTING.ru.md).
