# Процедурные PBR-текстуры Filamentra

[English](TEXTURE_GENERATION.md)

Для каждого из 18 пресетов каталога Filamentra предоставляет *типичную*, некалиброванную пару карт нормалей и шероховатости. Это процедурно смоделированные типовые поверхности филаментов, **а не** лабораторные измерения или карты производителей. Они дают полезный предпросмотр без заявления о физической точности.

## Что создаётся

- Цветные карты нормалей OpenGL в пространстве касательных (+Y) и карты шероховатости в оттенках серого.
- Детерминированные бесшовные пары PNG размером **384 × 384** с предполагаемым физическим размером **8 × 8 мм**.
- Предпросмотр нейтральной сферы для каждого пресета при одинаковом виртуальном освещении; это не рендер Fusion.
- Галерея по адресу **/textures.html** и **data/textures.json** с указанием происхождения данных.
- Три файла на пресет: **normal_gl.png**, **roughness.png**, **preview.png**.

Все исходные рецепты, оценки и начальные значения генератора случайных чисел на основе SHA-256 собраны в `tools/generate_texture_maps.py`. Для нового пресета обязателен рецепт генератора; сборка отклоняет отсутствующие рецепты и рецепты без соответствующего пресета.

## Сборка и CI

    python -m pip install 'jsonschema>=4.21,<5' 'numpy>=2,<3' 'Pillow>=11,<13'
    python tools/validate_catalog.py
    python tools/build_demo.py --out dist

Сборка демо **автоматически запускает генерацию текстур**. Проверка в CI и GitHub Pages создают их заново. Проверка охватывает JSON-схемы, наличие рецептов для пресетов, воспроизводимость и бесшовность краёв и публикует галерею и все PNG текстур как скачиваемый артефакт workflow `filamentra-typical-pbr-textures`. Сгенерированные PNG **не коммитятся** в Git.

Все пресеты каталога ссылаются на относительные пути пакета внутри `assets/presets/<id>/...`; те же пути создаются в выходном каталоге Pages `dist/`.

## Важные ограничения

- Существующие числовые значения шероховатости и амплитуды зерна — оценки Filamentra по типу поверхности, а не измеренные оптические свойства производителя.
- Карта шероховатости уже включает базовое числовое значение. При установке в Fusion не следует повторно умножать карту на это значение без проверки.
- Карты нормалей описывают *типовую микротекстуру материала*, а не реальные линии слоёв печати. Высота и направление слоёв относятся к отдельным параметрам процесса печати.
- Для Galaxy, Marble, Sparkle и Wood могут также понадобиться карты альбедо или эффекта, смешиваемые с цветом конкретного филамента. Карты нормалей и шероховатости не отражают все цветные включения.
- Для полупрозрачных пресетов отдельно обрабатываются пропускание и показатель преломления; одних карт нормалей и шероховатости недостаточно.
- Предпросмотры сфер предназначены для быстрого визуального сравнения, а не проверки поведения окна просмотра или Render в Autodesk Fusion.

## Релизы

Версии профилей ресурсов должны соответствовать версии выпуска каталога. При внедрении в аддон Fusion определяйте пути текстур относительно локального кеша каталога, последовательно применяйте физический масштаб текстуры и не изменяйте незаметно Appearances в уже сохранённых моделях после изменения генератора.
