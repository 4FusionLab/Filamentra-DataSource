# Демо каталога Filamentra — CI GitHub Pages

[English](DEMO_PAGES.md)

Это интерактивная статическая визуализация исходного каталога PLA/PETG Filamentra только для чтения. Она **не** является живой лентой, не выполняет API-запросы к GitHub и не изменяет каталог.

GitHub Pages был включён, а первоначальная публикация прошла успешно 2026-11-04 ([workflow развёртывания](https://github.com/4FusionLab/Filamentra-DataSource/actions/runs/41860887983)). Адрес опубликованного сайта:

https://4fusionlab.github.io/Filamentra-DataSource/

## Первоначальная настройка GitHub

1. Откройте **Settings → Pages** репозитория.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Build and publish catalog demo**.
4. Нажмите **Run workflow**, выберите `main` и запустите выполнение.
5. Задание проверяет исходный JSON, собирает статические ресурсы и развёртывает результат в Pages. После успешного развёртывания сайт доступен по адресу выше.

Если GitHub сообщает об ошибке политики организации, разрешений Pages или защиты среды, исправьте её в настройках репозитория или организации перед повторным запуском. GitHub Pages нужно явно включить; добавление workflow само по себе не гарантирует публичный адрес.

## Когда обновляется сайт

Демо **публикуется только вручную**. Для свежего снимка используйте **Actions → Build and publish catalog demo → Run workflow**. Push каталога в `main` запускает отдельную проверку, **а не** развёртывание Pages.

Каждое развёртывание проверяет исходный JSON, синтаксис JavaScript браузера и созданный снимок до публикации; ошибки блокируют публикацию. Pull requests не развёртывают Pages. Независимый `validate.yml` продолжает выполнять проверки без развёртывания.

Демо — статический снимок коммита `main`, полученного соответствующим развёртыванием Pages, а не живая API-лента.

## Локальная сборка

Выполните из корня репозитория:

```shell
python -m pip install "jsonschema>=4.21,<5" "numpy>=2,<3" "Pillow>=11,<13" "CairoSVG>=2.7,<3"
python tools/validate_catalog.py
python tools/build_demo.py --out dist
npm install --no-audit --no-fund --package-lock=false
npm run build:viewer
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Веб-сервер необходим, поскольку интерфейс загружает `data/catalog.json` через `fetch`.

Для генерации предпросмотров сборка использует NumPy, Pillow и CairoSVG и копирует `demo/index.html`, `demo/app.css` и `demo/app.js` в `dist`. Отдельная сборка просмотрщика использует закреплённые зависимости JavaScript. Публикуемый JSON создаётся во время сборки из существующих `catalog/brands/*/*.json` и `catalog/presets/*.json`.

## Возможности

- Фильтры производителя, PLA/PETG и линейки продуктов.
- Полнотекстовый поиск по названию цвета, линейке, производителю, коду производителя и HEX.
- Образцы RGBA/HEX производителя, документированные измерения физических отпечатков и приближения для многоцветных и градиентных вариантов.
- По умолчанию показаны отобранные цвета с подтверждёнными источниками. Включите оценочные ориентиры HEX или отключите фильтр образцов, чтобы увидеть неполные исследовательские записи.
- Отдельные ссылки на источник производителя, независимое измерение образца и приблизительный цветовой ориентир.
- Записи только с названием, если числовой цвет недоступен.
- Панель деталей со ссылками на происхождение, кодами цветов производителя и оценочной шероховатостью поверхности.
- Совместимая с мобильными устройствами компоновка со сворачиваемыми фильтрами и адаптивной сеткой образцов.
- В главном блоке показаны шесть подтверждённых источниками цветов из созданного снимка каталога, а не выдуманные заглушки.
- На узком экране поле поиска остаётся видимым даже при свёрнутых дополнительных фильтрах.
- Просмотр сеткой или группами по линейке, сортировка по названию цвета или производителю, точные счётчики производителей и удаляемые метки активных фильтров.
- Сравнение до четырёх цветов рядом в одном формате статического процедурного предпросмотра; каждый элемент сохраняет происхождение, код производителя и ссылку на исходный источник.
- Ссылки на фильтры каталога и цвета с параметрами URL, которыми можно делиться, включая прямой переход к выбранному цвету.
- Компактные сведения о цвете, сравнение и копирование ссылки одним нажатием, раскрываемые технические параметры внешнего вида.
- Улучшения фокуса клавиатуры и работы на мобильных устройствах, включая неактивную закрытую панель деталей и размер шрифта поиска, удобный для телефона.
- Образцы в главном блоке открывают соответствующие реальные записи каталога.

Сравнение помогает относительному выбору, но не является калиброванным измерением различия цветов. HEX с источником, измеренный печатный образец и процедурный рендер поверхности — разные виды подтверждений. Для сравнения намеренно используются предварительно созданные изображения, а не четыре одновременных контекста WebGL. Интерактивный просмотрщик деталей сохраняет существующий оптический ориентир с логотипом 4FusionLab для полупрозрачных материалов.

Для локальных регрессионных проверок интерфейса перед ручной публикацией:

```shell
node --test tests/demo_ux.test.mjs
node --check demo/app.js
```

Интерфейс приближает несколько образцов производителя плоским CSS-градиентом. Это **не** рендеринг Fusion 360 и не физически точная симуляция экструзии многоцветного филамента.

## Безопасность и область

Посещение демо не изменяет каталог. Частные токены не раскрываются, а статический сайт содержит только уже публичные данные. Данные каталога и клиентские сценарии собираются во время CI. После включения публичный сайт GitHub Pages доступен всем.

Если репозиторий станет частным, публичное распространение может потребовать отдельной проверки видимости и доступа.

## Визуальный дизайн

Интерфейс каталога следует продуктовому направлению Material Workbench. На оформление повлиял [unslop](https://github.com/heydamir/unslop) Damir Sokolovsky (CC BY 4.0): спокойные нейтральные цвета и элементы управления, согласованные отступы и типографика, сдержанные акценты и реальные цвета филаментов как основное визуальное содержание. Это независимая адаптация, а не официальный выпуск unslop.

Градиенты карточек многоцветных филаментов представляют сочетания цветов из источника; они намеренно **не** являются декоративными градиентами интерфейса или калиброванными физическими рендерами.
