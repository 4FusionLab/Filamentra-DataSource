# Аудит цветовых референсов — 4 ноября 2026

[English](COLOR_REFERENCE_AUDIT.md) | Русский

> **Область:** PLA и PETG. Подтверждения цвета и свойств поверхности или оптики имеют разные уровни достоверности. Проверка дополнила неполные цвета в существующих линейках; калибровка физического цвета не заявлялась.

## Иерархия подтверждений

1. **Образец производителя** (`hex_source: manufacturer` или `rgba_swatches` производителя). Это код цвета, опубликованный производителем или сохранённый в его официальной программе, но **не обязательно** измеренный цвет отпечатка.
2. **Измеренный образец** (`hex_source: measured`, с методом/прибором и освещением). Такой цвет имеет смысл только вместе с условиями измерения.
3. **Оценочный визуальный референс третьей стороны** (`hex_source: estimated`, `visual_data_status: estimated`, `color_reference_url`, `color_reference_note`). Часто это экранный образец, **не** официальный RGB производителя. Использовать для предпросмотра с явной отметкой неопределённости.
4. **Только название** (`visual_data_status: name_only` без числового образца). Достоверное название продукта/цвета известно, но обоснованный экранный цвет указать нельзя.

**Каждая запись продукта по-прежнему сохраняет официальный `source_url` производителя**, подтверждающий существование продукта или варианта. Сторонний цветовой референс хранится отдельно. Нельзя переводить `estimated` в `manufacturer` без публикации производителя именно для данного оттенка.

Демо различает HEX **производителя**, **измеренного физического отпечатка** и **оценочный**. В отобранном представлении по умолчанию показаны только подтверждённые данные производителя или непосредственно задокументированные измерения отпечатков; оценки включаются пользователем отдельно. GitHub Pages публикуется **только при ручном запуске процесса**; изменения `main` запускают отдельную проверку исходных данных.

- ELEGOO: **147 существующих** записей получили явно оценочный сторонний HEX; добавлены **29** названий цветовых вариантов из каталога производителя без числового цвета.

- Всего записей, впервые получивших цвет: **243** (147 + 60 + 30 + 6).
- **Ни один новый цвет не помечен официальным HEX производителя** только потому, что он указан на стороннем сайте.

4. **DeepLee:** один продукт только с названием.
5. **ERYONE:** существующему высокоскоростному PLA добавлен цвет; официальный каталог содержит дополнительные **подтверждённые производителем линейки** для импорта, но их визуальные данные нужно исследовать независимо, а не массово выводить из названий.

**Визуальная точность продукта остаётся отдельной задачей калибровки Fusion:** необходимо проверить шероховатость, отражение, оттенок, пропускание и влияние направления слоёв на отпечатанных образцах. Одних онлайн-референсов для определения этих свойств недостаточно.
